# Roadmap разработки SQL Assistant MVP

## Часть 1: Скелет и Безопасность (Backend Infrastructure) 🏗️

*Цель: Подготовить фундамент, настроить защиту и базовые эндпоинты.*

- [ ] **Окружение:** Создать структуру папок согласно `TASK.md`. Настроить виртуальное окружение и `requirements.txt`.

- [ ] **Конфигурация:** Реализовать `backend/config.py` для загрузки `config.json` и `.env`.

- [ ] **Утилита безопасности:** Создать `scripts/generate_key.py` для генерации SecretKey.

- [ ] **Auth Middleware:** Реализовать `backend/auth.py` (bcrypt-проверка заголовка `X-Secret-Key`).

- [ ] **FastAPI Core:** Настроить `main.py` с CORS, Rate Limiting (`slowapi`) и базовыми эндпоинтами (`/`, `/config`, `/generate`).

- [ ] **Тест:** Убедиться, что `/generate` возвращает 401 без ключа и 200 (заглушку) с верным ключом.
  
  ## Часть 2: «Мозг» приложения (LLM Service) 🧠
  
  *Цель: Реализовать логику общения с ИИ и надежный парсинг ответов.*

- [ ] **Validation Service:** Реализовать `backend/services/validator.py` для проверки промпта на инъекции и оффтоп через `gpt-5.4-nano`.

- [ ] **LLM Service:** Реализовать `backend/services/llm.py` с системным промптом, требующим строгий JSON.

- [ ] **JSON Normalizer:** Написать логику очистки ответа от Markdown-оберток и мусора.

- [ ] **Трекинг:** Реализовать `backend/services/usage_tracker.py` для записи токенов в `usage.json`.

- [ ] **Тест:** Проверить через Postman/Curl, что сервер возвращает структурированный объект `{mermaid_code, sql_query, explanation}`.
  
  ## Часть 3: Оболочка (Material You UI) ✨
  
  *Цель: Верстка современного интерфейса с акцентом на UX.*

- [ ] **Layout:** Создать `frontend/index.html` с Tailwind CSS. Сетка: Sidebar + Main Content.

- [ ] **Sidebar Tools:** Слайдер температуры (с блокировкой по конфигу), селектор моделей, поле ввода с поддержкой `Tab`.

- [ ] **Auth Modal:** Реализовать модальное окно ввода SecretKey при первом входе (сохранение в `sessionStorage`).

- [ ] **Vibes (Animations):** Настроить плавные переходы (Hyprland style) через CSS-кривые Безье, прописанные в ТЗ.

- [ ] **Тест:** Убедиться, что интерфейс адаптивен и все элементы управления визуально реагируют на действия.
  
  ## Часть 4: Интеграция и Финальный Лоск 🔗
  
  *Цель: Соединить фронт с бэком и добавить интерактив.*

- [ ] **API Connection:** Связать кнопку «Сгенерировать» с эндпоинтом бэкенда через `fetch` (обработка 401, 429, 500 ошибок через Toast).

- [ ] **Mermaid Render:** Подключить `mermaid.js`, настроить рендер диаграммы в акцентном цвете.

- [ ] **SQL Highlight:** Интеграция подсветки синтаксиса (Highlight.js) и кнопки «Скопировать SQL».

- [ ] **Typewriter Effect:** Реализовать посимвольный вывод объяснения для «живого» интерфейса.

- [ ] **Live Editor:** Добавить возможность ручной правки Mermaid-кода с мгновенным обновлением диаграммы.

- [ ] **Чек-лист:** Прогнать проект по финальному чеклисту из раздела 12 `TASK.md`.
