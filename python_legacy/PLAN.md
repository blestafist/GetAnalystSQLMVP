## Часть 1: Скелет и Безопасность (Backend Infrastructure) 🏗️

*Цель: Подготовить фундамент, настроить защиту и базовые эндпоинты.*

- [x] **Окружение:** Создать структуру папок согласно `TASK.md`. Настроить виртуальное окружение и `requirements.txt`.

- [x] **Конфигурация:** Реализовать `backend/config.py` для загрузки `config.json` и `.env`.

- [x] **Утилита безопасности:** Создать `scripts/generate_key.py` для генерации SecretKey.

- [x] **Auth Middleware:** Реализовать `backend/auth.py` (bcrypt-проверка заголовка `X-Secret-Key`).

- [x] **FastAPI Core:** Настроить `main.py` с CORS, Rate Limiting (`slowapi`) и базовыми эндпоинтами (`/`, `/config`, `/generate`).

- [x] **Тест:** Убедиться, что `/generate` возвращает 401 без ключа и 200 (заглушку) с верным ключом.
  
## Часть 2: «Мозг» приложения (LLM Service) 🧠
  
*Цель: Реализовать логику общения с ИИ и надежный парсинг ответов.*

- [x] **Validation Service:** Реализовать `backend/services/validator.py` для проверки промпта на инъекции и оффтоп через `gpt-5.4-nano`.

- [x] **LLM Service:** Реализовать `backend/services/llm.py` с системным промптом, требующим строгий JSON.

- [x] **JSON Normalizer:** Написать логику очистки ответа от Markdown-оберток и мусора.

- [x] **Трекинг:** Реализовать `backend/services/usage_tracker.py` для записи токенов в `usage.json`.

- [x] **Тест:** Проверить через Postman/Curl, что сервер возвращает структурированный объект `{mermaid_code, sql_query, explanation}`.
  
## Часть 3: Оболочка (Material You UI) ✨
  
*Цель: Верстка современного интерфейса с акцентом на UX.*

- [x] **Layout:** Создать `frontend/index.html` с Tailwind CSS. Сетка: Sidebar + Main Content.

- [x] **Sidebar Tools:** Слайдер температуры (с блокировкой по конфигу), селектор моделей, поле ввода с поддержкой `Tab`.

- [x] **Auth Modal:** Реализовать модальное окно ввода SecretKey при первом входе (сохранение в `sessionStorage`).

- [x] **Vibes (Animations):** Настроить плавные переходы (Hyprland style) через CSS-кривые Безье, прописанные в ТЗ.

- [x] **Тест:** Убедиться, что интерфейс адаптивен и все элементы управления визуально реагируют на действия.
  
## Часть 4: Интеграция и Финальный Лоск 🔗
  
*Цель: Соединить фронт с бэком и добавить интерактив.*

- [x] **API Connection:** Связать кнопку «Сгенерировать» с эндпоинтом бэкенда через `fetch` (обработка 401, 429, 500 ошибок через Toast).

- [x] **Mermaid Render:** Подключить `mermaid.js`, настроить рендер диаграммы в акцентном цвете. *(Исправлено: используется mermaid.render() API)*

- [x] **SQL Highlight:** Интеграция подсветки синтаксиса (Highlight.js) и кнопки «Скопировать SQL».

- [x] **Typewriter Effect:** Реализовать посимвольный вывод объяснения для «живого» интерфейса.

- [x] **Live Editor:** Добавить возможность ручной правки Mermaid-кода с мгновенным обновлением диаграммы.

- [x] **Чек-лист:** Прогнать проект по финальному чеклисту из раздела 12 `TASK.md`.
