## 🔧 Исправленные проблемы

### 1. Рендеринг Mermaid диаграмм
**Проблема:** Диаграммы не отображались, показывался только текст кода  
**Решение:** Переход с устаревшего API на `mermaid.render()` с генерацией уникальных ID  
**Файл:** `frontend/index.html:431-464`

### 2. Стилизация Mermaid
**Проблема:** Диаграммы не соответствовали цветовой схеме интерфейса  
**Решение:** Настройка themeVariables с использованием акцентного цвета  
**Файл:** `frontend/index.html:255-273`

### 3. Форматирование объяснений
**Проблема:** Markdown форматирование и неправильные переносы строк  
**Решение:** Промпт изменен на plain text, добавлен `white-space: pre-wrap`  
**Файлы:** `backend/services/llm.py:61-76`, `frontend/index.html:474-477`
