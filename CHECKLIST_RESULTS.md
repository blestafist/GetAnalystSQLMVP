## Запуск приложения

```bash
# 1. Активировать виртуальное окружение
source venv/bin/activate

# 2. Запустить сервер
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# 3. Открыть в браузере
http://localhost:8000
```
